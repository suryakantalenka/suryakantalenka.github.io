Interactive Braille Learning System

An embedded learning concept designed to make Braille practice interactive, portable and accessible.

Embedded systemsSpeech inputTactile outputAudio feedback

Project overview · 01

Tactile learning paired with auditory feedback.

The Interactive Braille Learning System explores how embedded systems can support visually impaired learners in reading and practising Braille.

The supplied project concept calls the system the Innovative Braille Learning Machine. It combines voice recognition, Bluetooth communication, a microcontroller, electromagnetic actuators and audio output.

Proposed operating flow · 02

From spoken input to a Braille character.

  1. 01Speak

    The learner speaks a letter or word.

  2. 02Decode

    An application decodes speech and sends the input to a microcontroller through Bluetooth.

  3. 03Form

    Electromagnetic actuators raise and lower metal pins to create the Braille character.

  4. 04Reinforce

    Audio output speaks the character, combining tactile and auditory feedback.

Proposed capabilities · 03

01

Portable learning

Wireless, rechargeable operation intended to make practice available in different learning environments.

02

Educator feedback

A screen provides visual feedback to teachers and supporters while the learner uses the tactile surface.

03

Interactive practice

Quizzes and games can make repetition more engaging and help reinforce character recognition.

04

Broader access

Multilingual voice recognition and progress tracking are proposed for learners and educators.
